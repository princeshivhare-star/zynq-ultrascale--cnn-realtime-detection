# yolov5_usb_webcam_onnx
# YOLOv5 ONNX USB Webcam Detection  This project demonstrates live object detection using YOLOv5 ONNX models on a Xilinx ZCU104 board. The project supports streaming from a USB webcam and displaying live detections in a web browser via Flask and XILINX ULTRASCALE+ ZYNQ ZCU104 evaluation kit
